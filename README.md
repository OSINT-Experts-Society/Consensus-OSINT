## Key features

### Coverage and maintenance

- **Expert-maintained coverage.** Our team aims to review all 19 source projects weekly and evaluates new OSINT projects as they emerge. The latest completed review is dated above. Suitable modules are tested, improved and integrated; broken modules are retired.
- **Keep investigations current.** Search newly added lookup sources, or recheck saved identifiers and see newly discovered matches, changed details and inconclusive results.
- **Choose your search size.** Guided username and email searches offer **Quick** (up to 300 checks), **Custom** (enter a number) and **Full** (all eligible checks). Settings changes the default for this session; each search can override it. Eligible enrichment stays enabled, and email domain analysis is separate.
- **Balanced limited searches.** `--top 500` and Quick aim for 50/50 site checks and modules, filling unused slots from the other group. Limits apply per username/email after exclusions; email's module-only plan uses the available modules. Stored ranks order each group, not verified current popularity. Modules do not guarantee returned enrichment. Continue the full search to add remaining coverage, or use `--full`.
- **Automatic update checks.** Managed installs check for updates at startup and notify you when an update is available or ready to use. Repair and rollback are built in.

### Investigation workflow

- **Follow new leads automatically.** Enable recursive search to investigate usernames, email addresses and linked accounts discovered in your results, expanding your search without entering each new lead yourself.
- **Enriched results.** Go beyond found/not found with available profile details, including names, biographies and linked accounts. Inspect the returned information, see source coverage and compare details across results.
- **Bulk search and advanced controls.** Process lists, generate username variations, filter sites and categories, and use proxies.
- **Save your investigation.** Keep named investigations with multiple saved searches, notes and relevant/unrelated decisions. Storage is local and explicit; optional recent-search history is separate.

### Reports and integrations

- **Reports and evidence graphs.** Export HTML, PDF, CSV or JSON; explore connections visually, with XMind and Neo4j exports also available.
- **AI integration.** Optional MCP support connects compatible assistants to Consensus lookups and results.

## Install

The Windows install bundle is recommended for most users. It sets up Python and the required dependencies automatically.

### Windows quick install — no coding needed

1. **Download:** open [Releases](https://github.com/OSINT-Experts-Society/Consensus-OSINT/releases), find **Assets**, and save the `Consensus-<version>.zip` installer to your Downloads folder.
2. **Extract it:** right-click the ZIP, select **Extract All**, then **Extract**.
3. **Install:** open the extracted folder, double-click **Install.cmd**, and wait for installation to finish. Keep your internet connection on.
4. **Open Consensus:** choose **Launch Consensus** when prompted, or press the Windows key, type **Consensus**, and open the Start menu shortcut.
5. **Start searching:** choose **Username**, **Email** or **Phone**, then enter what you want to look up.

### Other installation options

For macOS, Linux, PyPI or a terminal-based installation, use the options below.

| Platform | Double-click installer | Bundle from terminal | Install from PyPI | Install from source |
| --- | --- | --- | --- | --- |
| **Windows** | **Install.cmd** | Run `.\Install.cmd` in CMD or PowerShell. | [Python + PyPI instructions](#install-from-pypi) | [Git + Python instructions](#install-from-source) |
| **macOS / Linux** | Use the terminal option. | Run `sh install.sh`. | [Python + PyPI instructions](#install-from-pypi) | [Git + Python instructions](#install-from-source) |

Both bundle options set up Python and dependencies for you. Run terminal commands from the extracted folder. Internet access is required.

After a bundle install, open a new terminal:

```console
consensus
```

### Install from PyPI

Already have Python 3.10 or newer? Install Consensus with its lookup modules and PDF reporting:

```console
python -m pip install "consensus-osint[modules,pdf]"
consensus
```

Use `py` instead of `python` on Windows, or `python3` on macOS/Linux, if required.

## Start searching

1. Choose **Username**, **Email**, **Phone** or **Bulk search**.
2. Enter your query. Include the country code for phone numbers.
3. Review matches, open enriched details, then **Save report**, **Filter results** or **Search again**.

Choose **I Follow up** in results to continue a full search, search new sources, recheck or view changes. Choose **8 Investigations** from the main menu to save searches and notes together. Newly discovered profiles are not necessarily newly created accounts; an unavailable result does not prove deletion.

Press **Esc** or **S** to stop an interactive scan; type `exit` to quit. Enable **Recent searches** in Settings to keep up to 10 searches locally. History is off by default.

## Update Consensus

| Installed with | How to update |
| --- | --- |
| **Windows, macOS or Linux installer** | Run `consensus update`. |
| **PyPI** | Run `python -m pip install --upgrade "consensus-osint[modules,pdf]"`. |
| **Git / source** | Run `git pull`, then repeat the platform install command under [Install from source](#install-from-source). |

Restart Consensus after updating. Installer-based installations also check for updates when Consensus starts and install them automatically by default.

<details>
<summary><strong>Repair, rollback and update controls</strong></summary>

Open **Settings → Installation & updates** to check versions, install updates, restart or recover an installation.

To update from an installer ZIP, extract it, then select **Choose bundle** in Settings and choose the extracted folder, or run its installer. Restart to apply changes.

| Command | Action |
| --- | --- |
| `consensus update --repair` | Repair the installed version. |
| `consensus update --rollback` | Restore the previous version and pause automatic upgrades. |

A manual update resumes upgrades after rollback. Set `CONSENSUS_AUTO_UPDATE=0` for notifications only, or `CONSENSUS_NO_UPDATE_CHECK=1` to disable startup checks.

**Moving from a source install?** Choose **Switch to managed installation** in the Updates screen and select the extracted bundle. Your configuration and report locations are preserved.

</details>

```console
.\.venv\Scripts\consensus.exe
```

**macOS / Linux**

Use `python3` above if required, then:

```console
.venv/bin/python -m pip install ".[modules,pdf]"
.venv/bin/consensus
```

Add `mcp` to the extras for AI integration, for example `".[modules,pdf,mcp]"`. PDF support is included in managed installs.

## Use Consensus with AI assistants

<details>
<summary><strong>Connect an assistant using Model Context Protocol (MCP)</strong></summary>

Install the MCP extra in your Python environment:

```console
python -m pip install --upgrade "consensus-osint[modules,pdf,mcp]"
```

For clients using an `mcpServers` configuration, add:

```json
{
  "mcpServers": {
    "consensus": {
      "command": "consensus",
      "args": ["mcp", "--transport", "stdio"]
    }
  }
}
```

Use the full path to the installed `consensus` executable if your assistant cannot find it. Client configuration screens vary; select a local stdio server and use the same command and arguments.

The server provides username, email and phone lookups, paginated results and detailed evidence. Example request: **“Use Consensus to search my username YOUR_USERNAME across up to 20 sources, then summarise the matches and inconclusive results.”** Lookups contact external services; review your assistant's tool permissions before running them. Returned profile text is evidence, not instructions.

</details>

## Common questions

**What does Consensus search?** Usernames, email addresses and phone numbers using the installed lookup catalogue. Coverage varies by identifier type, enabled modules and available provider access.

**How are the 19 projects combined?** Their lookup modules and rules are standardised into one catalogue. Default searches reconcile overlapping lookup routes before presenting unified results; Consensus does not simply run 19 complete searches.

**Are results just found or not found?** Available evidence can include profile names, biographies and linked accounts, alongside each result's status. A match is a lead, not proof of a person's identity; errors and inconclusive responses do not establish absence.

**How do I install and update it?** Choose the [installer or PyPI](#install), then follow the [update instructions for your installation](#update-consensus).
